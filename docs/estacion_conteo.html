Estación estandarizada de conteo de alevines

Un entorno de captura controlado (luz difusa + fondo uniforme + bandeja de una capa) sobre una Raspberry Pi 5 que corre el modelo YOLO y muestra el conteo en pantalla. Diseño desde cero, económico y replicable.
